# 🔐 Redes & Segurança — Laboratórios Práticos

> Trilha **DEV + Security**: laboratórios de redes documentados como *writeups*, mostrando não só o resultado, mas o **raciocínio** por trás de cada configuração e diagnóstico.

Sou **Ewerton Amorim**, estudante de Sistemas de Informação e instrutor de tecnologia, construindo uma carreira na convergência entre **desenvolvimento e segurança da informação** (AppSec / DevSecOps). Este repositório reúne meus laboratórios práticos de redes — a fundação técnica sobre a qual construo as competências de segurança.

Cada laboratório segue a mesma disciplina de um relatório profissional: objetivo, topologia, plano de endereçamento, configurações, **evidências de teste** e **análise de troubleshooting**. A ideia não é só "montou e funcionou", mas documentar *como* o problema foi diagnosticado — que é o que importa no dia a dia da área.
